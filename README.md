# 《复变函数与积分变换》习题汇编

本项目将教材中习题一至习题八的指定页面整理为可编译的 LaTeX 文档，保留了原题号、公式、分项以及题目所需插图。

## 主要文件

- `复变函数与积分变换_习题汇编.tex`：LaTeX 源文件
- `figures/`：习题所需插图
- `复变函数与积分变换_习题汇编_TeX.zip`：包含源文件和插图的完整压缩包

## 编译方法

请使用 XeLaTeX，并连续编译两次以生成正确的目录和交叉引用：

```powershell
xelatex "复变函数与积分变换_习题汇编.tex"
xelatex "复变函数与积分变换_习题汇编.tex"
```

编译所需的主要宏包包括 `ctex`、`amsmath`、`amssymb`、`mathtools`、`enumitem`、`graphicx`、`float` 和 `hyperref`。
