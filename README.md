# 《复变函数与积分变换》习题汇编与详细解答

本仓库收录《复变函数与积分变换》课程习题的 LaTeX 整理稿及分章详细解答，内容覆盖复变函数基础、解析函数、复积分、级数、留数、共形映射、傅里叶变换与拉普拉斯变换。资料按照教材章节编排，适用于课程学习、课后复习及教学参考。

解答以原有演算过程为基础，在不省略必要步骤的前提下补充定理适用条件、计算依据、易错事项与多种解法，并对全书的符号、图形、题号和排版格式进行统一。

## 编写与校订规范

- **结构统一**：每题依次列出题目、分析思路与详细解答。
- **过程完整**：保留必要的代数变形、求导、取极限、分情况讨论及证明步骤。
- **条件明确**：注明积分公式、留数定理、变换性质等结论的适用条件。
- **多解并列**：对于具有不同思考价值的方法，分别给出完整解法并说明联系。
- **符号规范**：统一虚数单位、指数函数、实部、虚部、辐角及积分变换记号。
- **图形规范**：集合边界可取时使用实线，不可取时使用虚线；排除点使用空心点；从区域中删除的线段使用红色标示。
- **逐题核验**：对公式、运算、逻辑衔接、题号与图形位置进行交叉检查。

## 使用方法

### Overleaf

1. 下载所需的 ZIP 压缩包。
2. 在 Overleaf 中选择 **New Project → Upload Project** 并上传压缩包。
3. 将编译器设置为 **XeLaTeX**。
4. 分章解答与完整合订版均选择 `main.tex` 作为主文件；习题汇编选择 `复变函数与积分变换_习题汇编.tex` 作为主文件。
5. 点击 **Recompile** 完成编译。

各分章压缩包均为独立工程，无须另行上传 TeX 文件。使用完整合订版时，不得删除或重命名 `figures` 文件夹中的图形文件。

### 本地编译

建议使用 XeLaTeX，并连续编译两次，以生成完整目录及正确的交叉引用。
