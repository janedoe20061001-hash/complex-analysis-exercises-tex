## 编译方法

在 Overleaf 中选择 **New Project → Upload Project**，上传上述 ZIP，并将编译器设为 **XeLaTeX**，主文件选择 `复变函数与积分变换_习题汇编.tex`，然后点击 **Recompile**。

本地请使用 XeLaTeX，并连续编译两次以生成正确的目录和交叉引用：

```sh
xelatex "复变函数与积分变换_习题汇编.tex"
xelatex "复变函数与积分变换_习题汇编.tex"
```

编译所需的主要宏包包括 `ctex`、`amsmath`、`amssymb`、`mathtools`、`enumitem`、`graphicx`、`float` 和 `hyperref`。
