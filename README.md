# 《复变函数与积分变换》习题与详细解答

本项目整理《复变函数与积分变换》习题一至习题八，并在题目汇编的基础上，逐章编写适合初学者阅读的详细解答。

我们的目标不只是把教材习题从扫描页中转录出来，而是逐步形成一套完整、严谨、带有学习引导的习题解答：让刚学完相应章节的同学能够看懂题目从哪里入手、为什么采用这种方法、计算中容易错在哪里，以及同一道题还能怎样思考。

## 解答的编写原则

- **先讲思路，再写过程**：说明题型识别、切入点和所用结论，避免只有一串计算。
- **步骤完整但不机械**：基础计算写清关键变形，证明题交代假设、逻辑连接和结论成立的范围。
- **保留一题多解**：只要不同方法具有学习价值，就按方法一、方法二并列，而不是只保留最短解法。
- **从学生视角解释易错点**：特别关注辐角象限、定义域、定理使用条件、解析与可导的区别，以及复对数和复幂的多值性。
- **逐题核验计算与证明**：检查运算、公式适用条件与证明逻辑，补齐遗漏步骤，并按初学者的阅读需要控制详略。
- **图形重新绘制**：不直接使用手绘图。实线表示边界属于集合，虚线表示边界不属于集合；排除点用空心点表示，并统一坐标轴、标注和阴影规则。
- **面向 Overleaf**：源文件采用 XeLaTeX 和中文 LaTeX 宏包，尽量减少平台相关设置。

## 在 Overleaf 中使用

### 查看分章详细解答

1. 下载相应章节的 Overleaf ZIP。
2. 在 Overleaf 中选择 New Project → Upload Project。
3. 上传 ZIP 后，将编译器设置为 XeLaTeX。
4. 主文件选择 main.tex，点击 Recompile。

每个分章 ZIP 都是独立工程，可以直接上传，不需要另外复制图片或宏文件。

### 查看完整习题汇编

上传 [习题汇编 Overleaf 压缩包](复变函数与积分变换_习题汇编_勘误修订版.zip)，将编译器设置为 XeLaTeX，并选择 复变函数与积分变换_习题汇编.tex 作为主文件。

本地编译时建议连续运行两次 XeLaTeX，以生成正确的目录和交叉引用。
