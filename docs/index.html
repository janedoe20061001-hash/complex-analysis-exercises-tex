课堂提问与动画说明

动画把每个点沿直线从 z 移到 f(z)，即 wt = (1 − t)z + t f(z)。蓝色网格线来自原图横线，橙色网格线来自原图竖线。两图的箭头使用同一长度标尺，超出图框的部分会被裁切。

进度为 100% 时，局部箭头乘以同一个复数 f′(z)。当它非零时，两支箭头一起转过 arg f′(z)，长度都乘以 |f′(z)|。固定点的位置，转动原图里的箭头，观察这两个读数。
